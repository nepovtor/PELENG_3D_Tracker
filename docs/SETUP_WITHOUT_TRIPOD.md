# Две камеры без штатива: безопасная установка

## Что поставить на стол

MacBook — устойчиво, не на мягкой поверхности, крышка открыта так, чтобы встроенная камера смотрела на стол/объект. iPhone — задней камерой к объекту, **в горизонтальной ориентации**, на плотной нескользящей опоре. Начальная разница между центрами объективов 25–40 см; рабочий объект ориентировочно 1–2 м от камер, при хорошем освещении. Эти размеры — стартовый способ расположить камеры, а не гарантия точности.

### Вид сверху (условная схема)

```text
                    ОБЛАСТЬ НАБЛЮДЕНИЯ
                ┌────────────────────────┐
                │ шахматная доска/маркер  │
                └────────────────────────┘
                     ↗             ↖
                   ↗                 ↖
           MacBook                    iPhone
        ┌────────────┐           ┌────────────┐
        │ камера ①  ● │           │ ● камера ② │
        └────────────┘           └────────────┘
                  ⟷ примерно 25–40 см
```

### Вид сбоку (условная схема)

```text
                       объект с зелёным маркером
                       ○
   камера Mac ●  →      ○ ←  ● камера iPhone
  ┌────────────┐                 ┌────────┐
  │  ноутбук   │                ╱│ телефон│
  └────────────┘       ┌──────┐╱ └────────┘
══════════════════════════════════════════════
  стол                         упор с бортиком
```

## Без штатива, без опасных конструкций

- **Готовая обычная настольная подставка для телефона** — самый безопасный вариант. Убедись, что задняя камера не перекрыта, а конструкция не опрокидывается при касании экрана.
- **Две плотные книги + нескользящий коврик + устойчивый вертикальный предмет с бортиком**: книги ставь на стол, телефон опирай на них только при наличии устойчивого упора от соскальзывания. Проверь устойчивость без риска падения телефона; положение камеры должно сохраняться при небольших вибрациях.
- **Если нет безопасного способа закрепить iPhone под углом, не импровизируй на краю стола**. Положи телефон горизонтально задней камерой кверху и направь на область над столом, а Mac наклони так, чтобы зона пересекалась, либо найди простую устойчивую подставку. Такая геометрия менее удобна, но безопаснее шаткой «башни».
- **Не крепи iPhone скотчем к экрану Mac**, не прижимай его зарядным кабелем, не ставь на шаткий стакан, не накрывай аккумулятор мягким материалом, не размещай рядом с жидкостями.

## Условия для стабильной оптики

1. Проверь через панель Mac **оба реальных превью** до калибровки: обе камеры должны одновременно видеть доску и зелёный объект.
2. Старайся избегать яркого света прямо в объектив и блестящих поверхностей, а также разноцветных объектов в тех же HSV-диапазонах.
3. Убедись, что телефон не переходит в спящий режим во время потока, имеет заряд батареи и не перегревается; при необходимости подключи питание безопасным образом, кабель не должен натягивать крепление.
4. После стереокалибровки **не передвигай ни одну камеру**. Даже небольшое изменение их взаимного положения может сделать 3D неверным при визуально нормальном превью.
5. Для первой проверки двигай **ярко-зелёный шар медленно**, останавливая его на несколько секунд в разных местах. При программной Wi-Fi-синхронизации резкие движения увеличивают ошибку измерений.

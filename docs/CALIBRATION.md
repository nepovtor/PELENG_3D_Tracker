# Настоящая стереокалибровка PELENG

1. Открой `web/checkerboard.svg` в браузере, распечатай **A4 landscape / 100% / Actual size**. Доска состоит из **10×7 квадратов**, то есть **9×6 внутренних пересечений**. Номинальный квадрат 25×25мм. Отмерь 5 соседних клеток линейкой: должно быть 125мм; если это 122мм, в UI введи 0.0244 м.
2. Наклей лист на **жёсткий ровный картон** без изгибов и бликов. Установи камеры так, чтобы в обоих кадрах доска целиком была видна и хорошо сфокусирована. Изображения в рабочем потоке всегда 640×480; нельзя менять ориентацию iPhone/zoom после калибровки.
3. Сохрани минимум 12, лучше 20–30 пар. Примеры вариации: прямо перед камерами, ближе/дальше; левее/правее/выше/ниже центра; небольшие наклоны по всем осям. **Не снимай несколько пар без изменения позы.** Держи доску неподвижно при нажатии «Сохранить пару», иначе программный рассинхрон ухудшит результат.
4. Если UI не принимает пару, это значит OpenCV не нашёл 54 внутренних угла одновременно. Увеличь освещение, убери тени, поверни доску без обрезания углов, отойди/приблизься.
5. Нажми «Рассчитать калибровку» и дождись показателей RMS (в пикселях), оценённого расстояния между камерами (в метрах). Ядро отвергает решения с RMS >3px и некорректным базисом. **Малый RMS не доказывает абсолютную точность в миллиметрах.** Проверяй её отдельно на контрольных известных координатах.
6. Сохранённые матрицы профиля привязаны к Mac camera index, постоянному ID iPhone, версии его камеры/mode и размеру. Физический сдвиг, автоматическое изменение фокуса, частоты, кропа/зума и режимов камер может сделать профиль негодным — повтори процедуру.
7. Рабочие измерения: `cv2.undistortPoints` → геометрическая триангуляция → cheirality (точка впереди обоих объективов) → ошибка обратной проекции <3.5 пикселя → только тогда координаты добавляются к траектории и CSV.

**Отсутствие физического контрольного теста = отсутствие доказанной реальной точности.** Рекомендуется положить маркер в несколько известных неподвижных положений, измерить их рулеткой и вычислить абсолютную ошибку и отклонения.
